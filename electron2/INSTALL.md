# 生命之花 · 安装说明（macOS）

> 把人生的八个维度，画成一朵会呼吸的花。
> 记录只要 10 秒，回顾才是主角。数据只存在你自己的电脑里。

## 先说清楚一件事

这是一个独立开发的小工具，**没有做 Apple 公证**（那需要一个 99 美元/年的开发者账号）。
所以你第一次打开时，macOS 会拦一下，说「无法打开，因为无法验证开发者」或「已损坏」。
**这不是软件坏了，是没交过路费。** 下面两种办法任选一种，都是 macOS 官方留的口子。

## 装法

1. 打开 `生命之花-x.x.x-arm64.dmg`，把「生命之花」拖进「应用程序」。
2. 在「应用程序」里找到它，**右键（或按住 Control 点击）→ 打开**，在弹出的对话框里再点一次「打开」。
   - 注意：必须走右键菜单，直接双击不会给你那个「打开」按钮。
   - 只需要做这一次，之后就能正常双击了。

如果右键打开仍被拦（macOS 15 及以后偶尔更严），在「终端」里执行：

```bash
xattr -d com.apple.quarantine /Applications/生命之花.app
```

这条命令的作用是去掉「从网络下载」的隔离标记，只对这一个 App 生效。

## 你的数据在哪

- 数据库：`~/Library/Application Support/life-os/life-os.sqlite`
- 每日自动备份：同目录下 `backups/`，保留最近 30 份
- 设置页「关于」里会实时显示这个路径；「数据管理」里可随时导出 JSON / CSV 整份带走

## 它会联网吗

日常使用完全不联网：记录、回顾、季度会谈、手册，全部零网络依赖。
只有你自己在设置里填了 AI 的 API Key 并主动点击时，才会有一次外发请求。
没有账号、没有云同步、没有任何埋点回传。

## 系统要求

macOS 12 及以上，Apple Silicon（arm64）。Intel 机器与 Windows 版暂未提供。

## 卸载

把「应用程序」里的「生命之花」拖进废纸篓即可。
数据文件不会跟着删——想彻底清干净，再删掉 `~/Library/Application Support/life-os/`。
